Crie conversas com IA em TypeScript com o [@falai/agent](https://github.com/falai-dev/agent). Seu código decide o próximo passo; a IA lê as mensagens e escreve as respostas.

- Defina as etapas, os dados a coletar e as ferramentas que a IA pode usar.
- Faça a conversa avançar com mensagens, temporizadores ou eventos.
- Salve os dados e envie as mensagens pelo seu próprio app.

```sh
bun add @falai/agent
```

[Crie seu primeiro agente](https://github.com/falai-dev/agent/blob/main/docs/start/01-install.md) · [Documentação](https://falai.dev) · [Licença MIT](https://github.com/falai-dev/agent/blob/main/LICENSE)
