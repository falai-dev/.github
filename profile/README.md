Build AI conversations in TypeScript with [@falai/agent](https://github.com/falai-dev/agent). Your code decides what happens next; the AI reads messages and writes replies.

- Set the steps, the data to collect and the tools the AI can use.
- Move the conversation forward with messages, timers or events.
- Keep storage and message delivery in your own app.

```sh
bun add @falai/agent
```
