Crea conversaciones con IA en TypeScript con [@falai/agent](https://github.com/falai-dev/agent). Tu código decide el siguiente paso; la IA lee los mensajes y escribe las respuestas.

- Define los pasos, los datos que necesitas y las herramientas que puede usar la IA.
- Haz avanzar la conversación con mensajes, temporizadores o eventos.
- Guarda los datos y envía los mensajes desde tu propia app.

```sh
bun add @falai/agent
```
